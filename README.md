## نبذة عن المشروع
تحليل مقارن لنتائج اختبار القدرات في أكبر 3 مناطق 
بالمملكة العربية السعودية (الرياض، مكة المكرمة، 
الشرقية) للعامين 1444 و1445.

## أبرز النتائج
- متوسط الدرجات الكلي: 68.60
- أعلى درجة: 90.82
- الشرقية الأفضل أداءً: 69.41
- الطالبات أفضل من الطلاب في كل المناطق
- تراجع الأداء في جميع المناطق من 1444 إلى 1445
